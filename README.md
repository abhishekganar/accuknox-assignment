 AccuKnox Assignment
Candidate: Abhishek Ganar
This repository contains my solutions for the AccuKnox Backend/Platform assignment.


Problems


Problem 1 — eBPF TCP Port Filtering

An eBPF-based solution to drop TCP traffic destined for a specified port, with port `4040` as the default.


Problem 2 — Process-Specific TCP Filtering

An eBPF-based solution to allow traffic only on a specified TCP port for a given process.


Problem 3 — Go Concurrency

An explanation of the provided Go program covering goroutines, channels, buffered channels, function values, the four-worker loop, and why `HERE1` is not guaranteed to be printed.
